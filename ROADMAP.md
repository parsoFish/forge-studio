# Roadmap

Where forge-studio is heading, in order. There are no dates, and the order can change.

## Now

- **Documentation you can learn from.** A published site with a landing page,
  guides that follow Studio's own navigation, and reference pages, all checked
  against the code.
- **A stranger can start from scratch.** Someone new installs forge from the
  README and the site alone and runs the example factory to a merged pull
  request. Every question they have to ask is fixed in the docs.

## Next

- **A real project built through forge.** The example factory delivers a
  series of features on an outside project, within a fixed budget. A defect
  found on the way is fixed in forge, not patched by hand.
- **Version 1.0.** Released once a stranger has started from scratch and the
  real project has been built.

## Later

- **Your knowledge, your store.** The engineering knowledge forge keeps about
  itself moves out of the product and into a knowledge base you connect, the
  same way any project's knowledge connects.
- **More real projects.** Further feature campaigns on other kinds of project.
- **One spend limit for the whole factory.** Set a budget once; when spend
  gets close, the factory stops taking new work and lets running work finish.
