AGENTS.md — gitpulse

Contract for autonomous agents working this repo. Commands are the interface; scripts are the source of truth.

Commands

  • npm test — vitest, unit workspaces. The dev-loop gate.
  • npm run lint — eslint flat config; zero warnings.
  • npm run build — tsc + bundle; must pass before any PR.

Known suites

  • Snapshot suite runs nightly only (workflow_dispatch) — not part of the push gate. Do not add it to CI push paths.

Never touch

  • .github/workflows/release.yml — operator-owned release flow.
  • src/fixtures/generated/ — regenerated by pretest; edit the generator, not the output.

Conventions

  • Conventional commits; one concern per PR.
  • New features land with their tests in the same PR (bundle-sized work).
