## 3. Which roadblock is worth a forge fix or new tool?

Three patterns each cost multiple re-runs: (a) 18 zero-commit WI sessions because send-backs re-run the full WI chain from WI-1 rather than skipping already-green WIs; (b) adversarial review ran 3 full passes ($9.25) because the initial scope was incomplete — a pre-dev-loop "full failing test audit" step in the PM spec could prevent this; (c) CLA.md verbatim requirement wasn't enforced at the WI gate — the gate only ran `python3 -m pytest tests/test_legal_files.py`, but that test didn't exist until WI-5 wrote it, so the first write of CLA.md had no verbatim check until the adversarial review.

- (a) Skip already-green WIs on send-back — add a checkpoint/skip mechanism to the dev-loop runner
- (b) Full failing-test audit before PM decomposition — add a pre-PM gate step or brain constraint
- (c) Per-WI legal-text verification anchor — require a URL or hash in the AC, not just "verbatim"
- None — leave all three as-is
