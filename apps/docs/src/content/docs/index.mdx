## What you can do

<CardGrid>
  <Card title="Hand off whole features" icon="rocket">
    Describe an idea. An agent interviews you and drafts a plan for your
    approval. Then agents build it, review it and open a pull request while you
    work on something else.
  </Card>
  <Card title="Build your own factory" icon="puzzle">
    Arrange agents, skills and gates into a flow in Studio. A flow is data you
    can read and change, so the pipeline fits your project.
  </Card>
  <Card title="Keep what it learns" icon="open-book">
    After each merge, forge asks what went well and records it as knowledge.
    Planning agents read that knowledge before they design the next change.
  </Card>
</CardGrid>

## How it works

<Steps>

1. **Connect a project.** forge checks it can test, demo and release your code.

2. **Approve a plan.** Describe a change. An agent asks you questions, then writes the plan.

3. **Review the result.** Agents build and review the change. You merge the pull request or send it back.

</Steps>
