# Read a ground's own toolchain output in a run report

> Generated by `npm run stories -- --story ignored-born` from `tests/stories/ignored-born.story.mjs`. Do not hand-edit — edit the story and re-run it.

## 1. Open Studio on the Projects pillar

A run reports what changed in the project it stood on. Some of that is the project's OWN build output — a bundle, a coverage file, a TypeScript build stamp — which the project's .gitignore already calls disposable. Forge names those separately from a real containment failure, and names the rule that made the call, so an operator can tell "the toolchain ran" from "something wrote where it should not have".
