# Onboard a project from the Projects pillar

> Generated by `npm run stories -- --story proof` from `tests/stories/proof.story.mjs`. Do not hand-edit — edit the story and re-run it.

## 1. Open Studio on the Projects pillar

The Projects pillar lists every project forge manages. Each card carries the project it stands for, so the operator can pick one without reading the page.

![Open Studio on the Projects pillar](frames/01-open-studio-on-the-projects-pillar.png)

<details><summary>What you should see</summary>

- `data-page` is `projects-index`
- `data-page-ready` is `true`
- `data-fetch-status` is `ok`
- `data-card-type` is `project`
- `data-card-id` is `gitweave`

</details>

## 2. Click the first project card

The card is a real link to that project’s own page — the route is the project the previous beat found, not one written down in advance.

![Click the first project card](frames/02-click-the-first-project-card.png)

<details><summary>What you should see</summary>

- `data-page` is `projects`
- `data-page-ready` is `true`

</details>

## 3. Go back to the Projects pillar

The Projects pillar is one click away from anywhere in Studio.

![Go back to the Projects pillar](frames/03-go-back-to-the-projects-pillar.png)

<details><summary>What you should see</summary>

- `data-page` is `projects-index`

</details>

## 4. Click "Onboard a project"

Onboarding asks for the few things a Factory needs before it can build a repo: what to call it, the quality gate that judges its work, and the north star that tells a planner what it is for.

![Click "Onboard a project"](frames/04-click-onboard-a-project.png)

<details><summary>What you should see</summary>

- `data-page` is `projects`
- `data-project-id` is `new`
- `data-page-ready` is `true`
- `data-section` is `project-onboard`

</details>

## 5. Fill in the name, the quality gate and the north star — and under Advanced, the repo path — then press "Onboard project →"

Registering the project lands the operator on its page. Nothing linked here a moment ago — the route exists because the button was pressed, which is how every one of forge’s operator flows works.

![Fill in the name, the quality gate and the north star — and under Advanced, the repo path — then press "Onboard project →"](frames/05-fill-in-the-name-the-quality-gate-and-th.png)

<details><summary>What you should see</summary>

- `data-project-id` is `story-proof`
- `data-page-ready` is `true`

</details>
