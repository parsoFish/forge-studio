# Forge 1.0 — skills and tools to have in place before kickoff

> Companion to [`1.0.md`](./1.0.md). Researched 2026-08-28 across the official marketplace (286 plugins), `anthropics/skills`, `everything-claude-code`, `wshobson/agents`, `awesome-claude-code`, and the tool ecosystem (dependency-cruiser, knip, Playwright, Diátaxis, ADR, git hygiene). Rejection bar: unmaintained > 6 months, duplicates an installed skill, or a trust footprint (hooks on every tool call, network installs at launch, SaaS dependency) that conflicts with unattended lanes and the cull stance. Every kickoff prompt in [`1.0-kickoffs.md`](./1.0-kickoffs.md) names only skills listed here or already installed.

## 1. Install before the first session (one-time; ~10 minutes)

Run in order. All are hookless or single-banner-hook; none phone home at launch except the pinned Playwright MCP (installed per story session, removed after).

```bash
# refresh the two stale marketplace caches first
claude plugin marketplace update ecc          # cache is 2.0.0 / 2026-07-24; upstream 2.2.0
claude plugin marketplace update caveman      # cache is 2026-05-20; upstream 2026-08-27

# official plugins — user scope, no hooks
claude plugin install pr-review-toolkit@claude-plugins-official     # silent-failure-hunter + review lenses (M0-A, every M4 lane, M5-A)
claude plugin install claude-md-management@claude-plugins-official  # claude-md-improver: the CLAUDE.md ≤ 80-line cull (M0-C)
claude plugin install commit-commands@claude-plugins-official       # /clean_gone only — deletes [gone] branches + their worktrees (M1-A); ignore its /commit
claude plugin install session-report@claude-plugins-official        # per-lane token totals into the ledger OUTCOME line (every lane, at close)
claude plugin install claude-security@claude-plugins-official       # in-session vuln hunt with verify-every-finding (M4 library/apps lanes, M7)

# cherry-pick two ECC skills as plain SKILL.md dirs — never enable the ecc plugin (8 PreToolUse + 7 Stop hooks, install.sh runs npm install)
cp -r ~/.claude/plugins/marketplaces/ecc/skills/skill-stocktake   /home/parso/forge/.claude/skills/   # audit the 29 SKILL.mds under the cull stance (M0-C)
cp -r ~/.claude/plugins/marketplaces/ecc/skills/loop-design-check /home/parso/forge/.claude/skills/   # 4-condition veto for any loop; Goodhart/spin review (M5-A, M0-C theme)

# Diátaxis writer (github/awesome-copilot, MIT, 45-line SKILL.md, no scripts) — the story runner's doc fragments (M1-B) and the ≤25-file tree (M6-B)
mkdir -p /home/parso/forge/.claude/skills/documentation-writer && \
  gh api repos/github/awesome-copilot/contents/skills/documentation-writer/SKILL.md --jq .content | base64 -d \
  > /home/parso/forge/.claude/skills/documentation-writer/SKILL.md
```

Verify: `claude plugin list` shows the five official plugins; `ls .claude/skills` shows 12 dirs.
